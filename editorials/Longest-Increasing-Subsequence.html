  • Space: \(O(n)\)

Display math works too:

\[ \sum_{i=1}^{n} i = \frac{n(n+1)}{2} \]

Code

class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen = {}
        for i, x in enumerate(nums):
            if target - x in seen:
                return [seen[target - x], i]
            seen[x] = i
